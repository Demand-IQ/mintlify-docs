---
title: Narration & Voices
description: Choose the voice for your presentations and keep narration up to date as you edit slides.
---

Every slide in a Sales CoPilot presentation is narrated by a synthesized voice. The audio plays automatically as slides advance, with the script text highlighted word-by-word in sync.

## Choosing a voice

You set the voice when creating a template. In the **New Template** dialog, you'll see a **Use Premium Voice AI** toggle. This controls the voice quality used across all slides, FAQs, and Q&A responses in the template.

Pick the option that fits your use case — premium voices sound more natural but take slightly longer to generate.

## Regenerating audio after edits

When you save a slide with a changed narration script, the audio and word timings regenerate automatically as part of the save. You never have to remember a separate step to keep audio in sync with the script — if the save succeeds, the stored audio matches what you just wrote. If audio generation fails, the save fails too, so a slide is never persisted with a script that doesn't match its audio.

Saves that only change other fields — title, image, or context — don't trigger any new synthesis.

If you want to preview the new narration before saving, use the **Preview** button next to the narration script. It generates audio for the current script on demand — and skips regeneration on subsequent plays until the script changes again — so you only wait when there's something new to hear. When you then save the slide, the editor reuses that audio instead of synthesizing it again.

If you'd rather have the AI rewrite the script entirely from the slide image, click **Use AI to Generate Script** — this rewrites the narration based on what's in the image, using your template context as guidance.

## FAQ and Q&A audio

Audio for FAQ answers is generated automatically when you save a FAQ. If you edit the answer later, it regenerates automatically.

For the Q&A transition and resume prompts (in the **FAQs** tab under **Q&A Experience Settings**), audio is not automatic — after saving the prompt text, click **Generate Audio** to produce the spoken version.

## Checking audio status

Throughout the template editor you'll see status indicators on audio content:

- **Audio Ready** — the spoken audio is generated and ready
- **Generating...** — audio is currently being produced
- **Failed** — generation didn't complete; try regenerating

Each slide and FAQ has an audio preview player so you can listen before sending anything to a homeowner.

## Slides without narration

A slide can reach a live presentation without a narration script — for example, a bulk-uploaded image you haven't gotten to yet. Sales CoPilot handles these gracefully during playback: the slide dwells on screen for a few seconds and then advances to the next slide automatically, so the deck never stalls on a silent frame.

To catch these before you send anything, the Slides tab flags every slide missing a script with a **Needs narration** marker and shows a running count beneath the rail. The marker clears as soon as you save a narration script for that slide.
